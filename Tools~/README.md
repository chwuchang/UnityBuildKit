# BuildKit

这个文件夹由 [UnityBuildKit](https://github.com/chwuchang/UnityBuildKit) 生成。
This folder is generated by [UnityBuildKit](https://github.com/chwuchang/UnityBuildKit).

- `buildkit.json`：项目配置，提交到 Git / project config, commit it
- `secrets/`：密码和密钥，**不要提交** / passwords and keys, **never commit**
- 其他脚本由 Unity 菜单「BuildKit → 更新命令行脚本」更新，不要手动修改 / other scripts are updated via the BuildKit menu, don't edit them by hand

```bash
bash BuildKit/build.sh all          # Mac：双端出包并上传 / build & upload both platforms
BuildKit\build_android.bat          # Windows：出 Android 包 / build Android
```
